# VBTdroid logo assets

Everything here is regenerated by scripts, never hand-edited. Keep `scripts/` with the PNGs.

## Geometry (do not change while matching v2)

The plate mark is defined in `scripts/logo_v3.py`, copied verbatim from the v2 drawing
script and extended with the VBT arc text:

```python
PLATE = (512.0, 420.0, 280.0)      # centre x, centre y, radius
TRAILS = ((-92, 100, 22), (0, 120, 30), (92, 100, 22))   # dx, length, width
TRAIL_GAP = 40.0                   # trails start 40 px below the plate edge
MARK_BOUNDS = (232.0, 140.0, 792.0, 875.0)
plate outline 14, white ring 0.82R, hub 0.18R
```

The VBT face is sized relative to the plate radius, so it scales with the mark:

```python
cap  = 0.27 * plate_radius
base = 0.373 * plate_radius        # baseline circle
gap  = 0.01 * plate_radius         # equal visible gap between letters
```

## Generate

```bash
source ~/miniforge3/etc/profile.d/conda.sh && conda activate vbtdroid && python3 logo_v3.py
```

Outputs into `../final_v3/`:

| file | use |
|---|---|
| `logo_horizontal_{light,dark,mono_black,mono_white}.png/.svg` | lockups, 2200×700 |
| `app_icon_{light,dark}.png` + `_192` | store / preview icons |
| `splash_{light,dark}.png` | 1080×1920 splash art |
| `mark_{light,dark,mono_black,mono_white}.png` | transparent mark, 1024×1024 |
| `../final_v3/svg/` | vector versions |

`mark_*` is the source for the Android resources: crop to content, then fit to 63 % of a
432 px canvas for `ic_launcher_foreground` / `splash_icon_light`, and 92 % for
`brand_mark_light` / `brand_mark_dark`.

## Other scripts

- `plate_vbt_palettes.py` — plate face only (300 px radius), four palettes, no trails.
  Source of `plate_text/plate_vbt_*.png`.
- `plate_vbt.py` — VBT-only plate, top arc, 1024. Experimental sizing.
- `plate_flat.py` — VBT set horizontally above the hub, 1024. Experimental.
- `plate_wordmark.py` — full `VBTdroid` on the arc. Superseded: 8 letters cannot fit a
  1024 plate at a usable size, kept for reference only.

## History / decisions

- Text on the plate face argues against setting `droid` there: at 1024 px the whole word
  needs a 160–170° arc, which stops reading as "on the upper arc".
- The arc version was rejected by the user at small sizes; the final mark keeps VBT only.
- `final_v2` is the untouched baseline: same mark without the lettering.
